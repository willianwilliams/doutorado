Codigos e resultados de simulacao para o projeto de doutorado com sistemas hipercaoticos.

- `python_fast_offmsg_e5diag_article_params/`: simulacao Python/Numba dos metodos RKF5 e Euler, calculo de metricas de sincronizacao, tabelas em CSV/LaTeX e arquivo `JAM.mat` usado nos ensaios.

Para executar o projeto Python, entre na pasta do projeto e veja o `README.md` interno.
